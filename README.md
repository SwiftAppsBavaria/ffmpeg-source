# FFmpeg source for SwiftAppsBavaria apps

Source code, build scripts and the unmodified binaries of **FFmpeg** (LGPL v3) as shipped with apps by SwiftAppsBavaria.

FFmpeg is a project of [ffmpeg.org](https://ffmpeg.org). It is not developed by SwiftAppsBavaria. This repository
contains no code of our own; it only keeps the exact FFmpeg sources available for as long as the corresponding app
version is distributed, as the LGPL requires.

Each release corresponds to one app version and contains:

- the FFmpeg source code at the commit the binaries were built from,
- the build scripts used for that build (BtbN/FFmpeg-Builds),
- the FFmpeg files shipped in the app package, unmodified (the LGPL v3 license text is included there).
